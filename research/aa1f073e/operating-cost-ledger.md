**Why this stays blank.** Three independent official routes were tried — the regulator's comparison
tool, the regulator's survey documentation, and the national statistical report. Each either declines to
produce a property-level price (I1, I2) or produces a state-level average that its own publisher warns
against reading as a price (I5, I6). The state-level figure is also drawn from a different population
than the regulator's own data call, so blending the two would be unsound. No figure is published.

**Method note.** The comparison tool is an Oracle APEX application whose results require a form
submission; a plain page fetch returns only the introduction. This is a retrieval limitation of this
session, not a statement that the data do not exist. A person using the tool interactively can obtain
sample premiums for a ZIP code — but they would still be sample premiums for a hypothetical risk, which
is why the conclusion above does not change.
