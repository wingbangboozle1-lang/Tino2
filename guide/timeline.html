Deadlines in order.

The dated steps that can move the decision, from the date of death to the Proposition 19 claim deadlines. Each row links to the official rule.

Private facts withheldOfficial sources linkedSynthetic examples only
Why this page exists. The brief asks that the household agree, in writing and in advance, on what would make it choose each path — so that the outcome cannot be reverse-engineered from one favourable projection. A model cannot do that for you, and this page does not pretend to. It sets out, for every path, the condition to write down first, the falsifier that would void it, and the official rule the condition rests on. Every threshold cell is deliberately blank: filling one in from this public site would be a recommendation.
Sign first, then compute. Write the register on paper or in a private file, date it, and only then run the private model on verified inputs. A condition written after the figures are visible is not a pre-commitment, and a mix chosen after the numbers is just the best-fitting line from one projection.

how to use it

How to use this register

Each row above is one line of a private file the household keeps and dates. Fill only the columns that are yours to fill: the condition, the falsifier, and the date. Leave every threshold that requires a number blank until the verified comparables, adviser letters and quotes listed in the Questions register are in hand. When a condition fires or fails, write the date and the reason next to it. When the review date arrives, re-check the official sources linked in each row before relying on any rule that has changed.

  • Write the register before running any private projection, and keep the dated original.
  • Record every decision and its date next to the item, so a later reader knows what was chosen and why.
  • Never enter a private answer, address, rent, bill or account number on this site; keep the completed register offline.
  • Re-read the linked official page before acting; the rules and amounts above are dated 16 November 2026.
